Meet the actors

A hardware project is like a stage crew: several specialists work together, and each one should own a clear job.

The project is split by responsibility

A module should be easy to describe in one sentence. This repository mostly follows that rule: firmware talks to hardware, scripts talk to the board, and docs store evidence.

What they say to each other

A serial project is easiest to understand as a group chat. The laptop only sends tiny command messages; the board decides what each command means.

The command router is the switchboard

The switch statement is where a single letter becomes behavior. This is where you steer AI when adding or changing a serial command.

CODE 
    case 'D':
    case 'd':
      g_streaming = false;
      g_counting = false;
      g_detecting = true;
      Serial.println("DETECTING");
      break;
PLAIN ENGLISH

If the laptop sends uppercase or lowercase D...

turn off raw frame streaming.

turn off continuous text counting.

turn on detection packets.

print a human-readable status line.

stop checking other command cases.

i
Steering Prompt

Useful AI instruction: "Add a new serial command in handleSerialCommands, and make sure it disables incompatible modes before enabling the new one."
