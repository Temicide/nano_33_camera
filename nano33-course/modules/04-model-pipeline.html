How the model sees a smaller world

The camera sees a postcard-sized frame. The model wants a square passport photo. The firmware builds a precise crop-and-resize map between them.

Why preprocessing matters

Preprocessing is the promise that training and production see the same kind of image. Here, the camera captures 160x120 grayscale pixels, but the Edge Impulse FOMO model expects a 96x96 grayscale input.

160

Camera frame

Large enough to see the blister pack, small enough to fit in RAM.

96

Model input

The trained model only understands the input shape it was exported with.

int8

Tiny data type

The model uses compact values to keep memory use practical on the Nano 33 BLE.

The firmware refuses incompatible model exports

A compile-time check is like a measuring gate at the workshop door. If the model shape no longer matches the firmware assumptions, the build stops before upload.

CODE 
static_assert(kInferPixels == EI_CLASSIFIER_DSP_INPUT_FRAME_SIZE,
              "Edge Impulse DSP input must match a single grayscale frame");
static_assert(kFrameWidth >= kInferWidth && kFrameHeight >= kInferHeight,
              "Camera frame must be at least as large as model input");
PLAIN ENGLISH

Confirm the model input pixel count matches one grayscale frame.

If not, stop compilation with a message that explains the mismatch.

Confirm the camera frame is at least as wide and tall as the model input.

If the model is larger than the camera frame, stop before producing bad firmware.

The lookup map saves repeated math

A lookup table is a cheat sheet. The board computes where each model pixel comes from once, then reuses that map during inference.

CODE 
void initializeInferenceMap() {
  for (uint16_t x = 0; x < kInferWidth; ++x) {
    g_sourceXByInferX[x] = static_cast<uint8_t>(
        kModelSourceX +
        ((static_cast<uint32_t>(x) * kModelSourceWidth) + (kInferWidth / 2)) /
            kInferWidth);
  }
PLAIN ENGLISH

Start building the map from model X positions to camera X positions.

Visit every column the model will ask for.

Store the matching camera column in a compact byte array.

Offset into the crop area, then scale from model width to source width.

The half-width term rounds to the nearest source pixel.
