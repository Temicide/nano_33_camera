How pixels travel over serial

The board and laptop use a tiny shipping label: magic bytes say what kind of package is coming, then the payload follows.

Two packet types, two jobs

Serial is not automatically structured. The project creates structure by prefixing each binary packet with a short magic byte marker.

OVF1 Raw frame packet: header plus grayscale image bytes.
OVD1 Detection packet: header, bounding boxes, then the same grayscale image bytes.
JSON Single-shot count response for production checks and scripts.

Key Insight

When bytes cross a boundary, both sides need the same contract. In this project, the C++ writer and Python reader must agree on byte order, field order, and packet size.

The Python reader follows the contract

CODE 
def read_packet(ser):
    if not scan_magic(ser):
        return None

    header = ser.read(HEADER_STRUCT.size)
    if len(header) != HEADER_STRUCT.size:
        return None
