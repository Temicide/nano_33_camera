What this little counter actually does

Imagine a document scanner at a pharmacy counter: a camera sees the blister pack, a tiny model finds each pill cell, and the board reports the count over USB.

Start from the thing you can see

The project turns an Arduino Nano 33 BLE and OV7675 camera into a small medicine blister counter. The key trick is that the firmware runs the camera capture and the inference on the board itself.

1

Camera frame

The OV7675 produces a 160x120 grayscale picture, small enough for microcontroller RAM.

2

Model input

The frame is center-cropped and downsampled to the Edge Impulse model size: 96x96.

3

Serial result

USB serial sends raw frames, detection packets, or JSON count results to the laptop.

The main journey: send J, get a count

Think of the command as a ticket number at a service desk. The laptop sends one letter, and the board runs a complete capture-count-report cycle.
