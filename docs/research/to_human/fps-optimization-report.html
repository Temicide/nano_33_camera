Nano 33 BLE FPS Optimization

Goal: improve board FPS while keeping the OV7675 camera path and deployed Edge Impulse FOMO model, without sacrificing SRAM headroom.

Implemented

  • Precomputed the 96x96 model-to-camera sampling map once during setup.
  • Kept one 160x120 grayscale frame buffer and avoided adding a second image buffer.
  • Added T profile command for capture, inference, DSP, NN, postprocessing, and estimated FPS.
  • Reduced serial chatter in continuous count mode by omitting per-box debug lines.
